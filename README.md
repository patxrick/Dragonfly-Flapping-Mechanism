Dragonfly Flapping Mechanism using MATLAB and CFD
📌 Overview

This project presents the modeling and simulation of the flapping wing mechanism of a dragonfly using MATLAB and Computational Fluid Dynamics (CFD)-inspired aerodynamic analysis. The primary objective of the project is to study the aerodynamic behavior, lift generation, and energy-efficient flight mechanisms inspired by dragonfly wing motion.

The project focuses on understanding bio-inspired flight systems by simulating periodic wing oscillations, airflow interaction, and pressure distribution around flapping wings. The system demonstrates how natural insect flight mechanisms can be applied in the development of Micro Aerial Vehicles (MAVs) and bio-inspired robotic drones.

Analyzed the relationship between flapping frequency and lift generation
